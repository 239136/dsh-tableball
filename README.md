# TableBall · 统一宠物母球

Windows 独立 DSH 插件。采用用户选定的方案 C：**母球由游戏物理管理，宠物动画作为皮肤在同一画布绘制**。原桌宠窗口仅临时隐藏，正常退出和游戏崩溃后恢复。平时只注册右键菜单，不显示球台。

## 使用

1. **右键桌宠 → 更多 → 进入台球模式**。素材成功解码、恢复守护就绪后才隐藏原桌宠，显示游戏母球。
2. **球杆**：鼠标所在一侧是握杆端；按住左键蓄力，松手向另一侧击球。球运动时等待停稳再击球，默认Esc直接退出；关闭“Esc全局一键退出”后才用于取消蓄力。
3. **拖动皮肤甩球**：设置中切换操作，拖住画布上的宠物母球后甩出；不再拖外部桌宠窗口。
4. 右键打开最高层菜单：临时隐藏球台画布、冻结运动，不会被球或球杆遮住；点击空白关闭菜单；默认Esc直接退出整个球台。
5. **Ctrl+Alt+T**设置、**Ctrl+Alt+B**暂停/恢复桌面鼠标穿透、**Ctrl+Alt+R**重摆、**Ctrl+Alt+M**游戏内重力开关、**Ctrl+Alt+D**切换完全穿透但不停球，**Esc / Ctrl+Alt+Q**退出并恢复原桌宠。

默认“桌面优先”：只有母球/球杆及正在蓄力、拖动、摆球、菜单时捕获鼠标，其他区域直接操作原应用；球滚动时自动穿透，物理不暂停。先移到母球或现有球杆即可瞄准，移出其操作范围后回到桌面。Ctrl+Alt+D可完全穿透包括母球覆盖的位置，再按返回；这与暂停不同。需要旧操作时可选“专注击球”。

默认Esc是全局快速退场键：即使焦点在别的应用或正在打开菜单，按下也会隐藏球台、释放输入并恢复原桌宠。若需要应用自身的Esc，在设置关闭“Esc全局一键退出”；关闭后只在球台手势/菜单期间临时使用Esc，其余留给原应用。原桌宠在整个游戏会话结束时恢复显示。

## 圆心、大小和碰撞一致

- 物理引擎持有唯一的母球 x/y/radius；虚线轮廓、球杆、动画皮肤都读取它。
- 按动画帧透明像素边界裁掉空白，完整角色居中缩放到母球圆内；模型不会伸出碰撞圆却碰不到球。
- “母球相对大小”=1时与彩球同大；觉得宠物小可调大，皮肤、轮廓和碰撞同步放大，不会只改外观。
- 不再使用外部窗口透明边距猜中心，不再需要X/Y碰撞偏移校准，不启动60Hz外部宠物追踪器。
- 母球和其他球共用碰撞、反弹、摩擦与入袋计算；本版是双方动量交换，不再采用首版的无限质量外部击球器。
- 母球犯规最多扣20分，停稳后寻找无重叠位置回位；无安全位置时可点击合法空位摆球。

## 球面材质

彩球使用树脂球面的明暗、固定上左光源、柔和接触阴影与肩部高光；8号为黑球、9号带白色条纹。文件夹球改用珍珠底色与清晰图标，母球皮肤保留在同一个物理圆内并加轻微表面反光。轻微滚动装饰只存在于渲染层，不改变质量、速度、摩擦或碰撞半径。

## 单屏与文件夹球

开启时按原桌宠所在屏幕选定本局工作区；所有母球/彩球运动受同一屏边界约束。移除该显示器会安全退出。

“球的来源”可选常规九球或全部桌面目录的视觉副本。只读取名称、图标和能取得的位置：

- 不移动、删除、重命名文件，不遍历文件夹内容，不隐藏或重排 Explorer 图标。
- 跨屏项目的副本集中在本局屏幕，原位置仍保留；无法读取精确位置的项目明确提示并采用安全排布。
- 进洞收起副本，清台/重摆按原始快照归位，退出移除游戏层；真实桌面一直未变。
- 真实图标仍显示，游戏里的文件夹是副本，并非直接操纵 Explorer 图标。

## 原桌宠恢复保护

恢复日志写入用户DSH_HOME的tableball目录。原生守护只使用窗口API，匹配窗口句柄、进程ID及创建时间，避免误操作被复用的句柄或PID。

**守护由菜单控制器/受保护启动器创建，必须位于游戏进程树之外。** 游戏进程被强杀时，其子进程也可能被Windows清理，所以不能把恢复守护放回Electron游戏的子树。控制器还会在游戏结束时补充释放与恢复。

动画加载失败时不隐藏原桌宠。正常退出先撤掉游戏画面、停止视频和输入，再恢复原窗口并结束主循环；超时也有外部守护兜底。下次启动会检查遗留恢复日志。新C模式不修改原桌宠物理、大小或显示配置；仅兼容恢复首版遗留的配置日志。

## 当前边界

- 当前以一只桌宠窗口工作；多桌宠精确窗口选择未实现。
- 皮肤先接入该宠物待机动画循环，不模拟完整桌宠服务的所有动作、气泡或对话。
- 角色被缩放/裁入圆内，圆是明确的物理球边界；不是任意动画逐像素轮廓碰撞。
- 暂时隐藏并恢复的是原窗口；不额外改写桌宠自身的逻辑位置。
- 强制关机、原桌宠自身被关闭等情况下，下一次启动只能恢复仍然存在且身份匹配的窗口，不会重建已经结束的桌宠进程。
